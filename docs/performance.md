# 全尺寸与后台导出

原尺寸检视和导出共用按原片 SHA、白平衡、工作空间及像素参数索引的 float32 磁盘缓存。显示器/打印预览配置不进入显影缓存键。输入/结果帧只读租用，LRU 仅回收未使用帧；默认 2 GiB。界面“后台任务”可查看并清理闲置缓存，不删除原片、草稿或导出。

RAW 的 LibRaw 去马赛克仍整帧运行，但 uint16 结果逐条带转 float32、顺序写入缓存；调色按 128 行（带细节 halo）顺序写出，避免全尺寸输出浮点驻留副本。镜头、拉直、降噪和修复在请求独立的临时映射帧上工作，释放不再使用的输入。TIFF 在最终量化后按 Deflate 压缩条带写入，不建立完整 uint16 中间数组。JPEG/PNG 编码器仍需要完整 8 位图像；输出缩放通道与文字水印/锐化保留浮点计算。

进程独立缓存目录在正常停止时清理；冷启动只清理可确认已退出进程的缓存，不终止/删除其他运行实例。修改过的缓存文件按大小/时间戳失效，重新从原片构建。临时文件只在完整写入后发布。它不是抗磁盘位翻转的归档格式。

导出默认一路，可显式选两路；可用物理内存不足 3 GiB 时回退一路。CPU/磁盘负载可能使两路更慢，默认不提高。队列显示解码、镜头与局部调整、调色、缓存复用、编码阶段及粗估 ETA。估时根据当前阶段比例和本任务已完成照片，不能保证准确。取消/停止在条带安全点检查，原片快照/恢复语义保持。

详细数据与数值差异见 reports/p2-performance.md。
