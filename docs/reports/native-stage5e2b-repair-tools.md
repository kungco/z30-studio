# 阶段 5E2b：实际鼠标修复与克隆工具

2026-10-27，基线 `cd299b0`。沿用 5E1/5E2a 的线性浮点修复和绑定配方，新增真实桌面选点、原图取样、逐点强度和可撤销移除。自动瑕疵识别、轮廓调整、GPU 和完整迁移仍未完成。

`core/repair_view.rs` 将 Slint 画布、contain 留白、缩放和平移映射到已显示预览的像素中心，再转换为修复集合的 `w-1/h-1` 规范；不能复用语义蒙版的另一种坐标定义。点击画布外或留白不添加点，10 个逻辑像素内命中已有标记则选择。单像素图、横竖图、边缘和非有限输入另有回归。原片、皮肤、面部与修复标记使用相同显示矩形；标记不会写入导出。

`core/repair_plan.rs`、`editor.rs` 仅访问现有原始线性缩略图来规划取样，不因单击而重新解码或复制全尺寸图。修复默认提供可重新选择的确定性邻近取样，克隆必须显式指定来源。来源与当前显示的原片绑定、预览尺寸和缓存戳必须一致，规划前后复查；只复制至多 256 点的元数据。

`desktop/src/repair_workflow.rs` 独立管理工具状态、选择和有界后台规划。结果发布同时核对任务代次、编辑 revision、完整配方、显示来源和交互状态；切图、继续编辑、取消或弹窗使旧结果无法应用。切图或原片绑定变化清除临时来源。半径、羽化、强度通过 `editing.rs` 的既有手势历史分别撤销；整点新增、重新取样、移除和清除各为一步。界面模型按点集/选择/尺寸缓存，避免每 16ms 重建列表。既有 v6 草稿/v4 队列和 CLI 登录方式保留。

`main.slint` 提供可收起面板、模式/点位列表、蓝色取样与金色目标标记、显示开关和取消取样。拖动超过 4 逻辑像素才平移，不误加点；画布焦点下 Ctrl+Z/Ctrl+Shift+Z、Delete 和 Escape 可操作。实际点击发现 ComboBox 更换模型后会重置本地选项，现通过独立选项镜像和发布顺序修复；撤销后的提示也随记录刷新。弹窗阻止画布和修复编辑回调。

新增 `core/tests/repair_tools_contract.rs` 和几何单元测试，验证来源变动、缓存取代、精确取样、独立撤销及非法输入不污染历史；没有放宽旧像素容差。`tools/smoke_native_repair_tools.py` 启动真实程序，调用产品回调，验证缩放/留白/对比/弹窗、选点/参数/移除/恢复、隐藏标记不影响 TIFF，以及两份公开 Z30 NEF 的真正 RGB16 输出。开发工具 `saved_recipe_export` 从持久会话重新显影到新文件，逐字节核对实际界面导出；十组冻结 NumPy 参考仍是独立数值基准。第三份明确生成的 PNG 故意被测试脚本外部改写，用于验证旧缓存和取样失效，其他输入和公开 NEF 均保持 SHA 不变。

提交前验证：Rust **105 通过**，另两项外部 RAW/CPU 人脸 fixture 显式通过；完整 Python **180（RAW 无跳过）**、Node **31**、全目标编译通过。十组冻结修复参考最大误差 **4.768e-7**，原 `2e-6` 容差未变。新工具 **56 项**流程通过，其中真实全尺寸 RAW 导出占用计算锁时排队取样，随后切图或取消，旧任务不能追加到任一照片；冻结导出字节保持一致。computer-use 对生成样图实际点选修复、手动克隆、半径/强度、Ctrl+Z、独立撤销及放大平移通过，发现的问题已修正。鼠标验收和 QA 回调验收分开记录。

观测：新工具指针回调至就绪约 **0.09–0.25 秒**（含文件 QA 往返与预览，不能视为纯算法时延）；两份公开 RAW 新点流程峰值约 **793 MiB**、保留全尺寸缓存时约 **319 MiB**。这是功能观测，不是统计性能提升。最终还会用旧修复流程在干净新包上与 5E2a 的相同输入、导出 SHA/耗时/内存比较；最终 ZIP/源码 SHA、289 项（旧 233+新 56）完整流程与对应 CI 以本机 checkpoint 和 final-artifact 为准，提交前构建不作为最终分发物。

限制：尚无用户 Z30 人像及多肤色主观质量、自动祛痘、干净 Windows、高 DPI、多显示器或 GPU 验证；取样可能带入不合适纹理，需检查和撤销。邻近取样只是环形均值匹配，不是模型判断瑕疵或生成式填充。原片绑定仍基于路径/size/mtime/尺寸，不是完整内容摘要；缩略图取样质量不代表全尺寸纹理最优。256 点/累计区域和32/64 MiB持久预算保留。历史 Python 启动器偶发退出超时根因仍未闭环。无付费调用、模型下载、原片覆盖、登录更换、自动续跑或关机。
