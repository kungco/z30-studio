# 阶段 2E：编辑草稿、撤销与预览缓存基础

2026-10-25。基础接口和恢复验证通过；**九参数编辑、撤销和导出 GUI 仍未接线**，不能据此宣称暗房界面已经可用。

## 实际源码

- recipe.rs：每张照片的九参数与类型化相机/自动/日光 WB；严格反序列化/范围校验；单照片 50 步内存撤销/重做，重复值不消耗历史，撤销后新编辑丢弃 redo，非法参数不污染历史。AI 的原有九参数 Schema 不变。
- session.rs：原生草稿写 v2、读 v1/v2。v1 先在内存迁移，第一次保存 v2 前原子保留**原始 JSON 字节**到 session-v1-backup-*.json；备份失败阻止覆盖。路径/评分/旗标保留，参数按照片独立存储；坏 JSON/未知字段/版本/参数或磁盘 CAS 冲突仍拒绝覆盖。不是 Python .z30proj 的自动导入器，旧程序不一定能读 v2。
- editor.rs：单 worker 只缓存一个最多 1600×1600 的线性帧及共享中性显影，改参数复用解码，切照片/原片变化/RAW WB 变化失效；读取及渲染后复查文件状态。原始全尺寸帧及时释放，中性对照用 Arc 共享。RAW DLL 只接受显式绝对路径；没有配置时明确报错，不从照片项目加载可执行路径。
- worker.rs：工作闭包可持有线程独占可变缓存，原有 latest revision/取消/结果替换规则保留。main.rs 当前仍使用查看器读取，尚未切到这个编辑接口。
- 新 edit_preview_probe / native_edit_preview_benchmark.py 记录实际 RAW 冷/缓存预览；smoke_native.py 增加 --legacy-recovery 验证真实程序两轮重启及迁移备份。native_build.ps1 的 -EditProbe 是开发工具，Python 不随 EXE 运行。

## 测试与实测

34 项 Rust 通过，真实 RAW fixture 常规显式 ignored；移动 WB 类型后另行执行的 12/14 位全/半尺寸 fixture 1 项通过。新增回归覆盖两张照片独立恢复、v1 原字节备份且只备份一次、混入新参数的 v1 拒绝、无效参数不覆盖磁盘、50 步/redo 分支、缓存复用/清空/换图/原片变更、中性图不变、工作线程缓存状态保留。原 Python 163 / Node 31 项在本轮前面已通过，相关产品源码未再改动。

真实公开 14 位 Z30：原尺寸 3712×5568，核心预览 1067×1600；第一次中性预览约 3 秒，随后暖色显影约 .7–.8 秒、重复约 .7 秒；缓存命中、不再解码，中性对照共享，重复像素完全一致，原片 SHA 不变。实际 worker 峰值约 362 MiB。结果见 native-edit-preview.json。冷/暖参数不同，不能据此推导等工作量加速倍数；解码/缩放计时不包含最初的文件状态查询，也不是 GUI 首屏时间。

实际 EXE 用带 ICC 的全尺寸合成 JPEG 两轮启动，第二轮特意恢复 v1：评分/旗标保留，v2 默认参数完整，备份字节与 v1 完全相同；原图 SHA 不变，重复实例拒绝，退出均为 0（约 .082/.059 秒）。验证时 PATH 移除了 Python/开发工具，见 native-v2-migration-smoke.json。此为数据/进程验收，没有宣称自动点击/截图或实机色彩校准通过。
