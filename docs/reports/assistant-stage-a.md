## 用户流程

主界面输入中文目标、选择风格，点击“生成调色建议”。发送前检查框展示实际 JPEG 编码后再解码的两张预览、目标服务/模型、最终目标文字、当前九参数与白平衡模式。默认先生成建议；设置中仍可明确选择自动应用。沿用已有 Codex CLI 登录与兼容接口，没有新增付费依赖或自动重试。

建议就绪后直接显示临时试片和参数变化。0–100% 强度从分析开始时的原配方和模型原始建议重新计算，继续经过相同限幅、显影与画质回退；调强度不调用模型，不叠加上次试片。模型解释与本机像素检测分别标注。试片未应用时导出只使用已确认参数。

“查看调整前”在试片期间比较分析前的已保存编辑；确认应用退出比较模式，一次应用对应一步撤销。丢弃、手动编辑、换图、来源替换或退出使临时结果失效。试片不写入草稿或恢复记录。撤销后旧“AI 已应用”提示也会清除，避免把上次操作当作当前状态。
