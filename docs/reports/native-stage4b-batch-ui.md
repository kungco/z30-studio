# 阶段 4B：原生批量导出界面

日期：2026-10-26。此阶段将 4A 队列接入实际 Rust/Slint 窗口，阶段 4 仍在进行中。

修改 `native/crates/desktop/src/main.rs`、`qa.rs`、`ui/main.slint`：顶部加入“批量导出”；设置中选择逐张配方或将当前配方应用于全部照片，格式沿用 JPEG/PNG/TIFF16。选择新目录后，先一次性检查并保存全部任务，再按顺序在后台执行。窗口显示完成/运行/待处理/失败/取消数、每张任务的阶段与明细。暂停只在当前照片完成后生效；取消会停止当前任务并取消未开始任务；失败/取消可显式重试。关闭程序时先暂停队列并取消当前任务，重新打开只恢复暂停状态，不自动继续写文件。持久化失败后队列转为只读，避免覆盖损坏记录。

修改 `tools/smoke_native_batch.py`：仅替换文件夹选择器的 QA 输入，其他路径调用实际窗口回调。三张 2400×1600 PNG 顺序导出为 TIFF16，检查独立/公共配方、暂停/进程重启、已有目标不覆盖、删除冲突后显式重试、取消未开始照片后显式重试、全尺寸高位深、原片 SHA 不变。14 项检查通过；Rust workspace 50 项通过、1 项需公开 RAW fixture 按设计跳过；Debug 构建成功。用 Windows 窗口截图目视核对 1320×890 主界面和批量弹窗，按钮与文字可见；物理鼠标完成整批导出尚未验收。

保留现有 Codex CLI 登录方式，批量导出不调用大模型或收费接口。没有覆盖原始文件，也没有合并主线或发布正式版。

剩余风险：真实 Z30 NEF 的批量解码/导出、取消时的峰值内存、分辨率/DPI 变化、完全干净 Windows 和长时间连续运行还需单独验证。崩溃可能留下 `.z30-export-*.part` 临时文件，4A 会提示中断但当前未自动清理。当前全尺寸缓存仅为单张预览缓存，尚未建立批量专用的解码复用和可比较的性能/内存基准。
