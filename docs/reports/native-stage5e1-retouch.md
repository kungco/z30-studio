# 阶段 5E1：浮点克隆 / 均值匹配修复核心

2026-10-27，基线 `38f88e1`。本阶段只有原生核心 API 与开发探针，**未接入桌面、配方、撤销、保存和导出，不是已交付的自动祛痘功能**。原生可用界面仍是已验收的 5D 功能；5E2 继续做来源绑定和完整工作流。

## 实现

`native/crates/core/src/retouch.rs` 复用保留的 Python `spatial.py` 算法：在未量化线性 RGB 中双线性取样，圆形羽化克隆，或利用环形邻域均值匹配修复。取样始终读取不可变原图，连续修复的目标区域按顺序更新。选择取样点只运行一次，保存归一化位置，之后按该位置重放；六个邻近候选按环形 RGB 差异和确定性 x/y 次序选择。这不判断候选是不是皮肤或有没有瑕疵，后续 UI 必须允许检查和手动指定。

归一化中心按 `x × (宽−1)`、半径按 `radius × min(宽,高)`，与旧版一致；越界取样不写入目标。输出允许有效的 HDR 与有符号线性数据，不提前压到 0–1 或 RGB8。均值计算使用 f64 累加，结果仍为 float32。修正了审查中发现的差异：**没有环形有效像素时不应用非负截断**，与旧版一致；不是通过改小样例或放宽容差掩盖。

禁用时返回无分配的 passthrough；启用时只复制一次整个输出，取样和环形计算直接读像素，不创建逐修复点的大型临时图。每 32 行有取消检查，取消/失败丢弃新输出，原输入不变。参数/维度/有限值在写入前验证；最多 256 点，累计包围盒不超过 1.28 亿像素，超限明确报错。JSON 必须明确 heal/clone，未知模式/字段拒绝。

- `core/tests/retouch_contract.rs`、`fixtures/retouch.json`：冻结旧版 Python 输出，十组中心/边缘/越界/连续重叠/零强度/HDR/非方形/有符号/无环形像素对照。

- 进度、功能矩阵与原生使用说明：区分核心完成和桌面未实现。

## 验证

Rust **93 通过，2 外部 fixture 默认 ignored**；公开 12/14 位 RAW 和固定人脸在前阶段已显式通过，本阶段最终显式重测/干净构建及 CI 记录在 checkpoint。完整 Python **180 项全部通过（设置公开 RAW 目录，无跳过，45.46 秒）**；Node **31 通过**。

冻结参考与真正 Release 探针 **十组全部通过**。固定绝对 RGB 容差 `2e-6`，实测最大 `4.7683716e-7`；不变区域精确保持，HDR 大于 1 的数据保留，取样坐标误差小于 `1e-8`。原来九组数据及容差逐项比较不变，只新增无环形像素的回归。核心另覆盖 256 点/工作量、取消、不复制的禁用路径、源不变、坏输入、取样确定性和严格 JSON。

固定机器三轮交替模式、各自新进程，合成 **5472×3648 float**，32 个半径 .015 的小修复点：

| 模式 | 修复函数中位耗时 | 进程峰值 |
|---|---:|---:|
| 禁用 | .000003 s | 231.941 MiB |
| 克隆 | .03951 s | 460.168 MiB |
| 均值修复 | .03994 s | 460.172 MiB |

峰值增加约 228 MiB，对应一份全尺寸 RGB float 输出；不是无复制的全尺寸编辑。计数每 20 ms 采样，包含来源缓冲/结果验证；耗时包含输入验证和输出复制，不含照片解码、模型和导出。不代表真实照片画质、最坏 256 点或与旧 Python 的速度对比。
