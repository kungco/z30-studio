# 阶段 2E 性能补充：浮点 sRGB 插值

2026-10-25。develop.rs 的浮点 sRGB 转换改为 65537 点曲线加线性插值，保留黑端线性分段并固定纯白端点；输入不取整到 16 位，不引入 8 位中间数据。原有解析函数用于构建曲线，冻结 Python 语料与旧算法对照文件均未改写。

35 项 Rust 通过，1 项真实 RAW fixture 常规明确 ignored（前一步已显式通过）。新增 200 万点独立 float64 解析参考、单调性、黑白端点/范围回归，要求最大误差 <2e-6；原有画质阈值不放宽。

12/14 位全/半尺寸暖色+锐化四组重新与修正 Python 对照全部通过，最大误差 5.11e-6–6.52e-6，小于一个 RGB16 码值、低于原 2e-5 门槛，无非有限输出，原片 SHA 全部不变。native-gamma-warm.json 保留源码/二进制 SHA 与每组性能。

两组全尺寸暖色显影约 5.61/5.82 秒，优化前约 8.36/8.41 秒；峰值仍约 479 MiB。纯解码约 2 秒的不足未解决；原始 Python 显影约 5.5 秒，因此不能宣称整体比旧版更快。均是单次测量，没有稳定倍数承诺。

随后重新运行两份 NEF 的真实 JPEG/PNG/TIFF16 文件导出，全部通过独立 Pillow/tifffile 检查：ICC 相符、PNG/TIFF 与当前浮点量化逐点一致、TIFF16 均含 65536 码值、JPEG PSNR 超过 35 dB、原片和已有结果未改、无正常结束残留 .part。见 native-gamma-file-export.json。缓存预览再次通过，见 native-gamma-edit-preview.json。

原生 GUI 仍为查看器，编辑/撤销/对比/导出按钮尚未接入现成核心接口；AI、批量、人像与其余高级功能未迁移。用户实机/肤色灰卡、校准显示器/打印、干净 Windows、GPU/云推理未验证。保持原片、CLI 登录、无必需付费 API，不合并 main、不正式发布或关机。
