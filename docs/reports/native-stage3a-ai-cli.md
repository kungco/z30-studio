# 原生阶段 3A：Codex CLI 调色

日期：2026-10-26。范围是原生 Codex CLI 后端；阶段 3 的可选兼容 API/本机模型仍未完成。没有进行真实云推理请求，也没有读取 `auth.json` 或购买 API 额度。

## 源码改动

| 文件 | 实际行为 |
|---|---|
| `native/crates/core/src/ai.rs` | 九参数 JSON Schema、完整字段/数值/白平衡校验；按用户强度和曝光/色彩上限约束建议；对预览的通道到顶、白像素、亮度层次与色度测量并分档回退。 |
| `native/crates/core/src/editing.rs`、`export_job.rs` | AI 参数作为一条逐照片可撤销历史；复用原片大小/修改时间的只读快照，应用前复查。 |
| `native/crates/desktop/src/ai_cli.rs` | 复用本机 CLI 登录；将中性/当前预览各编码为最长边 1024 像素、最多 2 MiB 的无 EXIF/GPS JPEG；在独立临时目录中用结构化输出和只读、禁用 shell/搜索的 `codex exec` 运行，180 秒超时，取消时杀掉该子进程并清理目录。 |
| `native/crates/desktop/src/main.rs`、`ui/main.slint` | 一键自动调色、设置风格/自然语言目标/强度、只给建议及手动应用、分析报告、取消、手动重试。切图、编辑、重置、撤销或退出使旧任务失效，结果必须重新匹配照片、配方、编辑代数及原片快照。 |
| `native/crates/desktop/src/qa.rs`、`examples/fake_codex.rs`、`tools/smoke_native_ai.py` | 通过真实 Slint 回调与真实子进程验证任务生命周期；模拟 CLI 不进入发布包。 |

CLI 运行参数使用 `--ignore-user-config --ephemeral --skip-git-repo-check --sandbox read-only --disable shell_tool` 并禁用搜索；输入仅通过标准输入和两张临时图片传给 CLI。请求里含目标、RAW 标志、当前九参数和白平衡模式，不含原片路径、文件名、EXIF、GPS 或凭证。用户点击按钮会让所选在线模型看到这两张预览；界面在设置和任务状态中明确提示发送内容。程序不自动重试。

AI 输出不是“差值”，而是完整绝对九参数。解析拒绝缺失/多余字段、非数值、非有限/越界数字、修改白平衡模式及过长说明。自动模式先按曝光 1 EV、色彩 25 点等上限约束，再用同一预览缓存渲染候选；画质恶化则试 75%、50%、25%、0% 强度。回退依据是启发式像素指标，不代替校准显示器、灰卡、肤色或人工审片。

## 验证记录

- `cargo test --workspace --locked`：45 个核心测试、1 个桌面测试通过；1 个需显式公开 RAW 环境的核心测试按常规规则 ignored。新增测试涵盖严格输出、约束/画质指标、撤销和无元数据 JPEG。
- 原 Python `unittest discover`：171 项，169 通过、2 个公开 RAW 环境项跳过；Node 31/31 通过。
- `.development/native-stage3a-ai-quality-gray-raw.json`：模拟 CLI 的实际进程/原生 UI 回调共 61 项检查通过。自动应用和单步撤销、只给建议、模型越界拒绝、取消、编辑使旧任务失效、活动任务期间退出、临时 JPEG 清理、原片 SHA 不变均通过。
- 中性灰输入上，模拟模型提出温度 100，限定为 25 后像素检测进一步回退到 12.5（显示实际强度 50%）。这验证了真实渲染后的回退流程；高亮样片的 +1 EV 因肩部映射未触发所设恶化阈值，未把“强参数”本身误判为画质损坏。
- 公开 Z30 12/14 位 NEF 均进入同一原生 AI 预览/参数流程，模拟模型返回后维持中性对比预览且原片 SHA 不变。12/14 位的精确 RAW 几何/色彩/位深仍以 2G 报告的四组逐像素对照为准。本阶段没有改 RAW 解码、tone curve、ICC 或导出像素实现。
- 复跑原有 `smoke_native_editing.py` 全部 24 项 GUI/导出/退出检查；14 位公开 NEF 的同一曝光配方导出完整 5568×3712×3 TIFF16。与 2G 已保存的干净 Release 输出比较，62,005,248 个通道码值逐点相同，**整个 TIFF 文件 SHA-256 也相同**（`d0e41f460866d90be3cdb9c437d1b2ac4d6864307a61b4e7a33839165a22eec2`）；记录在 `.development/native-stage3a-raw-output-compare.json`。
- 用 Computer Use 实际点开原生 AI 设置、启动离线调色并查看分析报告；按钮、参数、撤销状态和布局可见。GUI 脚本测试是回调/进程验收，不把它当成用户真实照片的主观画质评价。
