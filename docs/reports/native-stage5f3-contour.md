# 5F3：本机面部轮廓与可确认的轻微修形

日期：2026-10-29。本阶段接通 468 点轮廓定位和四个保守的脸颊/下颌调整建议，复用已有浮点形变、配方、撤销、草稿与导出。它不是无条件自动瘦脸，也不代表原生迁移全部完成。

## 实现与数据边界

- `native/crates/vision/src/contour.rs`：固定模型哈希、旋转裁剪、RGB/像素中心约定、CPU 推理、468 点解码、姿态与置信度检查、双尺寸形变验证。面部至少 64 预览像素，置信度和 presence 至少 0.9；明显侧脸、截断面部、无效值和不安全几何拒绝处理。
- `native/crates/desktop/src/contour_workflow.rs`、`main.rs`、`qa.rs`、`ui/main.slint`：独立可取消后台任务、青色轮廓、强度、确认应用。分析使用已有中性预览的 Arc，不做全尺寸解码。建议绑定照片来源、显示尺寸、编辑版本和组件路径，过期结果不能应用。已有形变包括 0% 记录都不会被替换。
- `native/vendor/contour`、`tools/prepare_native_contour.py`、`package_native.py`、`native_build.ps1`：固定模型/许可/来源清单、组件拒绝覆盖与链接检查、随包声明及完整性检查。程序本身没有 Python/TFLite 依赖，不增加云端或付费 API，不修改 Codex 登录方式。
- `tools/validate_native_contour.py`、`tools/smoke_native_contour.py`、新资产与包测试：独立模型数值对照及实际进程的应用、撤销、恢复、过期结果和损坏组件检查。没有修改旧画质测试或放宽旧容差。

四个局部场的位移仅为支持半径的 7.5%，默认应用强度 60%。半径受眼、鼻、嘴关键点距离与图像边界限制；合成几何测试验证这些保护点和远处背景坐标保持原位，但不能据此保证真实背景、发丝和所有人脸都自然。保存的是普通源绑定形变参数，36 个轮廓显示点与后台任务不写入草稿。

## 模型来源与独立对照

使用 [yakhyo 的 MediaPipe ONNX 转换](https://github.com/yakhyo/mediapipe-face-mesh-onnx/tree/3bdf1e0d100a4c709766c051a0c9e9cdab1fed62)，模型 2,466,068 字节，SHA256 `3ca77cf59c18e4da0eccb46695bf604683fa564253e3385892981a5c274fb10f`；Apache-2.0 许可与 NOTICE 随包。使用 [Google 原始 face_landmark.tflite](https://storage.googleapis.com/mediapipe-assets/face_landmark.tflite) 作开发期对照，SHA256 `1055cb9d4a9ca8b8c688902a3a5194311138ba256bcc94e336d8373a5f30c814`。

独立 NumPy 计算旋转 ROI、零边界双线性取样、NCHW 输入和回映坐标；官方 TFLite 与 ONNX 推理分别执行。原图、镜像、竖幅画布、黑图四组通过，三组有脸返回 468 点和四项建议，黑图不产生人脸或建议。输入最大误差为 0，模型坐标最大误差 0.0001221 输入像素，回映归一化误差 2.124e-7；容差在测量前固定。纯模型推理约 1.7–1.9 ms，不包含加载、照片处理或界面时间。

## 限制

公开测试照片不是用户实拍 Z30 肖像，没有灰卡、校准显示器或主观自然度评价。肤色/年龄/脸型/遮挡多样性、侧脸、多人真实照片、GPU、混合 DPI 多屏和干净 Windows 尚未验收。模型按需加载会有额外延迟，当前 CPU 推理不提供强杀线程式硬超时。高级暗房、镜头配置、图库/同步、广色域和完整旧工作流仍需按总任务逐项迁移。
