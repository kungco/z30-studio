# 阶段 5E2a：原片绑定修复记录、保存与显影

2026-10-27，基线 `fdfd007`。5E1 的修复核心现在接入配方、撤销、草稿、预览、单张/批量 RGB16 导出与取消。**鼠标选点/取样/删除工具仍未实现；本阶段以开发探针生成记录验收，不能称为完整桌面修复或自动祛痘。**

`native/crates/core/src/repairs.rs` 保存不可变共享集合，包含原片绑定和 1–256 点；反序列化时就限制数量，未知版本/模式/字段、非法参数或超出 1.28 亿累计包围盒像素均拒绝。历史和导出快照共享点数据。来源与尺寸检查独立于人脸/皮肤，不把另一照片的坐标误用于当前照片。沿用路径/size/mtime/尺寸绑定，仍不是完整内容摘要。

`recipe.rs`、`editing.rs`、`rendering.rs` 在全局显影之前应用线性浮点修复，完成后及时释放临时修复缓冲。原图只读，禁用路径不分配修复图。整组变更为一步撤销，AI/全局调整保留记录，重置可撤销，公共批量只同步全局参数和白平衡，各片保留自己的位置。`editor.rs`、`export_job.rs`、`worker.rs` 和桌面 `main.rs` 接通协作取消：取代/取消/关闭令牌可进入修复的每 32 行检查，取消的结果不能发布。RAW 解码、全局显影和外部 I/O 仍只有阶段检查，不声称整个处理可被任意时刻强杀。

`session.rs` 写 v6/读 v1–6，`batch.rs` 写 v4/读 v1–4；首次迁移备份旧 JSON 原字节，旧版本夹带新集合拒绝。独占锁/CAS、原子不覆盖导出和坏草稿保护保留。256 张/32 MiB、512 任务/64 MiB 字节预算保留；点数和不可压缩蒙版同时取最坏值时可能先达到字节上限，不能宣称所有组合都可装满最大数量。

新增 `core/tests/repairs_contract.rs` 验证线性处理顺序、预览/真实 TIFF16、共享指针、撤销/AI/逐张批量冻结、损坏/来源/尺寸/取消和 v5/v3 原字节备份；新增 worker 令牌回归。旧版本测试仅更新当前写版本断言，新增旧格式夹带修复数据拒绝测试，没有删除或放宽既有像素容差。`tools/smoke_native_portrait.py` / `smoke_native_skin.py` 迁移断言更新为 v6。

`examples/repairs_workflow_probe.rs` 与 `tools/smoke_native_repairs.py` 使用实际 Source Binding 构造隔离草稿，启动真实 Slint 程序并调用既有预览/导出回调，不启用产品 HTTP 服务，不假装鼠标工具已经完成。

验证：Rust **98 通过、2 外部 fixture 默认 ignored**；完整 Python **180（含公开 RAW、无跳过）**、Node **31** 通过。新流程在提交前包含 PNG 恢复/无 ORT/调整/撤销/重置/冻结批量/重启/关闭、256 点重任务取消，以及公开 12/14 位 NEF 的非零修复、实际窗口 TIFF16 与核心参考相同、原片 SHA 不变；最终干净包增加两份 RAW 的真实 RGB16 检查。提交后的完整流程和对应 CI/哈希以 `.development/checkpoint.json` 为准，不将脏构建当成分发物。

提交前观测：合成 PNG 进程峰值约 34.7 MiB；重修复取消到新中性预览约 .205 秒。两份公开 NEF 的非零修复进程峰值约 789 MiB，保留一张全尺寸缓存后常驻约 316 MiB。数值是该机器的功能运行观测，不能作为统计提速结论。5E1 十组冻结旧算法参考与固定 `2e-6` 容差保留。

未验证：用户实拍 Z30 人像、各种肤色/细节的自然修复质量、干净 Windows、高 DPI、GPU。均值匹配不是生成式/Poisson 修复，取样区域可能有不合适的纹理，未来界面必须允许检查/改点/撤销。自动瑕疵识别、受限轮廓及完整高级暗房仍待实现。没有收费调用、模型下载、原片覆盖或 CLI 登录变化。历史 Python 启动器偶发退出超时也未因本次修复就宣称根因闭环。
