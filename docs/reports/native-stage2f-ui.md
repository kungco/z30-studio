# 2F：原生基础编辑和后台导出

2026-10-26。本阶段把已验证的核心接到真实 Slint 窗口；总体迁移尚未完成。源码为本报告所在提交，初轮验证 EXE 的源码标记是上一个提交加 dirty=true，不能冒充干净提交构建。最终构建收据保存于本机 .development/final-artifact.json。

## 实际修改

- core/editing.rs：每照片独立的配方与 50 步历史。拖动期间立即更新待存配方，停顿约 450 ms 合并一次撤销；切图、重置、撤销、退出前提交当前操作。最终配方持久化，历史不跨进程恢复。
- desktop/main.rs、main.slint：九参数、重置、撤销重做、原/后对比、取消/重试预览、导出格式选择、阶段状态和导出取消。预览使用现有 PreviewEngine 单帧缓存，不再每次滑动重新解码。sRGB 中间缓冲直接量化显示，不重复施加 gamma。
- 预览以请求版本及照片路径/配方共同验收，滑块防抖等待期间也废弃旧结果。切图会清空旧画面，参数恢复到对应照片；缩略图不保留整张预览。
- core/export_job.rs、export.rs：导出捕获独立照片/配方快照；按全尺寸重新读取、浮点显影、带 ICC 编码。正式文件原子发布前检查取消与原片元数据变化；写入/定位也检查取消，错误自动删除临时文件。已有目标在预检及发布竞争时都不被覆盖。
- 预览/全尺寸导出共享计算门，避免同时持有两份完整 RAW 解码；UI 保持独立响应。关闭时先保存、取消并等待本任务清理，不强杀其他程序。
- QA 为显式本机文件协议，无 HTTP/网络监听。生产回调、配方/缓存/导出路径与测试相同，仅省略测试时的文件选择对话框。另有独立 Computer Use 真实窗口检查。

## 验证

原测试未删改：163 Python、31 Node 全通过；Rust 从 35 增至 40 通过，默认仍有一个真实 RAW fixture 标为 ignored。2F 实际 EXE 的公开 12/14 位 NEF 已分别通过界面回调测试，包括全尺寸 TIFF16、切图后保持导出快照、取消、导出中退出、草稿恢复；这不是把 ignored 记成通过。

增加了整段拖动撤销、照片历史隔离、重置/分支、非法参数不修改配方、持久配方恢复、完整输出尺寸与精度、原片变化/取消、发布时目标竞争与临时文件清理等回归。初次新测试曾因多个格式共享测试目录而误数前一格式留下的竞争目标，已将每个格式的目录隔离；生产实现和拒绝覆盖断言没有被删改或放宽。

三个实际进程场景覆盖合成图、12 位 NEF、14 位 NEF，原片哈希均不变；本机只保留测试的导出文件。TIFF 使用独立 tifffile 验证 uint16、全尺寸和非 8 位扩展码值；JPEG/PNG 使用 Pillow 检查 ICC。v1 迁移字节备份、独占实例、v2 恢复、系统 PATH 无 Python 的原 smoke 也再次通过。

Computer Use 在隔离草稿中读到了真实 RAW 画面，实际设置曝光 +1 EV、观察画面变亮、点击调整前对比恢复较暗画面，并通过真正 Windows 保存对话框写出 3712×5568 的带 ICC JPEG。一次无截图几何的按钮点击返回工具错误，刷新截图后通过坐标完成保存；未当成第一次已经成功。检查发现格式框/取消按钮伸展过宽，后续构建限制了尺寸。未据此宣称所有 DPI、屏幕或用户照片已验收。

## 前后输出、耗时和内存

详细数值与构建 SHA 见 native-stage2f-ui.json。

- 用上一阶段已验证且 SHA 相同的独立 photo_export_probe，对 14 位 NEF 采用同一 +0.6 EV 配方；本轮实际 GUI 导出的 TIFF16 与它逐码值相同，最大差异 **0**。RAW/显影算法本轮没有改变。
- 同一 2400×1600 PNG 的两轮独立进程：旧查看器预览标记 443/436 ms，新编辑器 287/288 ms；峰值工作集约 95.18→95.80 MiB。只做两轮且未控制频率/缓存，不能宣称普遍提速；标记不是屏幕首帧。
- 14 位 GUI 完整 TIFF 导出约 3.49 秒，旧核心同参数解码 2.20、显影 .81、TIFF 编码 .43 秒。新 GUI 计时包含队列/轮询，旧探针另写 float dump 及其他格式，范围不同。
- 14 位新 GUI 测试峰值约 542 MiB，旧核心探针约 479 MiB。GUI 包含预览缓存、对比缓冲与窗口，不能把缓存收益说成全流程内存下降。
- 导出显影阶段关闭窗口：合成图约 .48 秒，14 位约 .86 秒，退出码 0，无最终输出及 .part。它证明这些场景的合作式取消，不证明外部解码器/磁盘永久阻塞时的硬超时。

## 残余限制

RAW DLL 仍由 Z30_LIBRAW_DLL 显式提供；对应源码/运行库/许可的最终分发、干净 Windows 验证属于下一步。源元数据校验不能发现刻意保持大小与修改时间的外部替换。强制断电/进程崩溃可能留下 .part，持久导出队列/启动恢复尚未迁移。大图解码/显影阶段的取消只能在阶段返回后生效，未实现独立导出子进程硬看门狗。

导出仍固定 sRGB；显示器 ICC、软打样、广色域、复杂 ICC/CMYK/HDR、裁剪/局部/高级暗房、AI、批量、人像及 GPU 仍须后续迁移。用户自有 Z30 样片、肤色灰卡/镜头网格/校准显示器/打印、真实云端推理未验证。CLI 登录方式未改，也未调用付费推理。

最后一次新布局窗口检查收到 Computer Use 的用户物理 Esc 停止信号，已立即停止桌面控制。修正后的 EXE 已通过 12 位 RAW 回调/进程全套检查，但最后一次新布局截图复验未完成；源码提交后的干净构建、远端同步和该提交 CI 待下一轮完成。
