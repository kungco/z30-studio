# 阶段 5D：独立肤色均匀与受限提亮

2026-10-27；基线 `14639d9`。本页记录提交前源码验收；当前提交的干净构建、ZIP 解压全流程和 GitHub CI 另见本机 `.development/checkpoint.json`。阶段 5 总体未完成，实际 Z30 人像/多肤色尚未验证。

## 行为与边界

“本机人像”增加肤色均匀、肤色提亮两个独立 0–100 滑块。先定位、识别并检查皮肤；新控件只在保存了皮肤区域后启用，默认零，零强度不改变原有输出。眼嘴、面部边界与语义区域共同约束两项效果。分别撤销/重做、逐张保存、无模型恢复、预览、单张/批量 TIFF16 使用相同配方。公共批量仍只同步全局参数/白平衡，每张保留自己的人像参数。

均匀控制只校正低频局部色度，以固定 256² 加权场和双精度滑动求和计算皮肤邻域 RGB/加权亮度之比；不把头发/背景纳入平均，不设定统一的“理想肤色”。单通道比例修正限于 ±0.08，再按强度、区域和暗部保护缩减。重新归一化保留 **显示 sRGB 中 .2126/.7152/.0722 加权值**，并使用共同向量步长约束色域；这不是物理线性亮度或感知色差不变的承诺。

提亮按当前亮度比例增加通道，增量不超过 `0.045 × 强度 × (1−当前加权值)`，再乘皮肤/暗部/高光保护。按最大通道共同限制增益，保持 RGB 比例，不独立裁断某一通道。黑白端点保持，灰色保持中性；局部光照/肤色变化仍需用户判断。两项均运行于原有未量化 float sRGB，之后才导出 RGB16。

## CPU / 内存基准

固定机器，Release，三个全新进程/模式，交替模式顺序；合成 float sRGB，脸占宽高各 80%，比公开图的脸大。只计 tone 函数，不含解码/柔化/导出/模型，不代表真实 Z30 人像。峰值使用 Windows 进程计数每 20 ms 采样，包含图像缓冲与验证。

| 输入 | 均匀中位数 | 提亮中位数 | 同时中位数 | 禁用/均匀进程峰值 |
|---|---:|---:|---:|---:|
| 512×512 | .0111 s | .0065 s | .0125 s | 短进程采样可能漏掉峰值，不作内存结论 |
| 5472×3648 | .6247 s | .4883 s | .7240 s | 231.922 / 235.637 MiB |

约 2000 万像素均匀与同时处理比禁用峰值约增加 **3.7 MiB**；固定场不复制全尺寸 RGB 缓冲。只是额外 tone 处理的观测，原有显影/导出的全流程内存仍更高。

## 残余风险

用户 Z30 人像、不同肤色/妆容/遮挡/极端光照及主观自然度未验证，不能以单张公开样图代替。256² 区域不保证细发/眼镜/小脸准确；颜色边界附近仍需检查，过强设置可撤销或归零。来源绑定继续使用路径/尺寸/mtime/像素尺寸，恶意保持元数据替换内容尚不能检测。损坏草稿整体保护，不具备逐照片修复 GUI。

自动祛痘/克隆、轮廓变形、GPU 与完整高级暗房仍待实现；干净 Windows、高 DPI/校准显示器未验证。新检测需要系统 VC++ x64，已有蒙版的恢复/处理无需该推理 DLL。保留 Codex CLI 登录及原 Python 基线，无新收费 API、无真实云推理/模型下载、无原片覆盖，不合并主分支或发布正式版。
