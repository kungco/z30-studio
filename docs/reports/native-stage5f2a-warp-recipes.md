# 阶段 5F2a：绑定原片的形变配方与导出

2026-10-27，基线 `cdd6c91`（5F1）。本阶段把形变接入真实渲染、草稿、撤销和队列，并提供已有形变记录的强度/清除控件。**尚无鼠标创建/拖动形变的入口，也没有自动人脸轮廓定位或一键瘦脸；开发探针生成的测试配方不能代替产品入口。**

`core/warps.rs` 保存不可变共享的1–4个控制点、原片绑定和0–1强度。调节强度只改变元数据，原控制点不重复缩放；100%保留精确原值，0%保留记录且输出与无形变逐位相同。每次形变仍受5F1的10%半径位移、防折叠、完整圆、80MP/映射步预算限制。路径、尺寸或文件大小/修改时间变化时拒绝应用；这是元数据绑定，不是完整内容哈希，不能识别刻意保留元数据的文件替换。

`rendering.rs` 在原位置的修复、显影、柔化和肤色处理完成后应用形变，防止已有蒙版错位。显影结果是编码后的浮点sRGB，新增类型明确的路径只对四个贡献像素解码，再在线性光中按同一组f64权重插值并编码回f32。黑白半像素为约`.735357`，不会错误平均成`.5`；保留负值/HDR，不量化成8位。多个控制点先合成坐标再采样一次，额外一份输出，不建立全图坐标图或第二份全图线性缓存；禁用不分配输出，沿用取消检查。

`recipe.rs`、`editing.rs`、`session.rs`、`batch.rs` 增加独立历史、重置、冻结批量和原字节迁移备份：草稿写v7/读v1–7，队列写v5/读v1–5。旧版本文件里出现新形变字段时拒绝解释，不静默丢弃。普通调色及AI建议只修改全局参数；公共批量同步保留各张原片的几何信息。恢复已有形变及导出不加载推理DLL。损坏或外部修改仍走受保护路径。

`desktop/main.rs`、`repair_workflow.rs` 与 `ui/main.slint` 提供已载入记录的0–100%强度、清除和撤销；预览失败时仍可清除失效形变，保留其他调色。活动形变下隐藏原位置的面部/皮肤/修复标记，并阻止新的原位置修复取样，避免在错误位置操作。原有蒙版/修复参数仍保存并参与形变前处理。当前限制需等后续映射工具解决，不能宣称现有选点工具可直接叠加使用。

提交前验证：Rust **121**、两项显式公开RAW/CPU人脸fixture、原有Python **180（含RAW，无跳过）**、Node **31**通过。新增四组独立NumPy sRGB/双向坐标冻结参考，加上旧八组线性形变，最大像素误差为0、坐标约3.55e-15；原十组修复及原容差不变。新增七组配方契约检查绑定、共享、源空间顺序、备份、历史、批量和零强度。少数旧测试只更新当前写入版本断言；旧版本种子和像素期望保留。

`warp_workflow_probe.rs` 与 `tools/smoke_native_warp.py` 在隔离目录驱动真实Slint回调，新增 **37** 项通过：恢复、独立强度/撤销/清除/重置、冻结队列、重启、无模型恢复、重任务取消、外部替换拒绝/清除恢复、两份公开12/14位NEF与核心TIFF逐字节一致、真RGB16和原片SHA不变。外部替换只改另建的合成fixture。提交前活动RAW峰值约790MiB，取消到默认预览约.21秒；这不是统计提速结果。原默认五份和既有非零修复两份RAW输出、耗时/内存对照及全部 **326（旧289+新37）** 项干净包流程、包哈希和同提交CI由本机checkpoint/final-artifact另行核验，不能拿提交前构建充当干净交付。

Computer Use在1322×892实际检查了新增面板、提示、50%滑块及独立撤销，预览指纹在撤销后精确恢复。窗口在后续操作前关闭并正常退出，停止继续输入；0%和清除由真实进程回归覆盖，尚未完成对应物理点击验收。高DPI/不同缩放未验收。

双线性采样可能软化纹理，局部背景也会移动；缩略图和全图只有数值/流程对照，没有真实人像主观验收。用户Z30人像、多肤色、自然轮廓、干净Windows、GPU和真实云模型仍未验证。没有付费调用、原片改写、CLI登录变化、主分支合并、正式发布、自动续跑或关机。下一阶段应补受限鼠标形变、坐标/旧结果保护及实际操作，自动轮廓还需独立关键点模型与许可验收。
