# 阶段 5B：原生面部定位与保守柔化工作流

日期：2026-10-26。阶段 5 的部分实现；皮肤语义分割、瑕疵、均匀肤色、轮廓形变和 GPU 尚未完成。

## 实际源码与行为

- `native/crates/core/src/portrait.rs`、`source.rs`、`rendering.rs`：归一化面部框/五点、原片路径摘要与大小/修改时间/尺寸绑定，共用预览和全尺寸导出的浮点处理入口。强度零精确旁路；活跃修饰遇到源文件变化会报错，不复用旧位置。路径摘要不是原片内容哈希；人为保持同一路径、大小和时间戳的内容篡改不在此元数据检测范围内。
- `recipe.rs`、`editing.rs`、`session.rs`：逐张人像配方、整次手势撤销/重做、AI 只改全局参数并保留人像、重置清除修饰。草稿写 v3、读 v1/v2/v3，迁移首次落盘前备份旧 JSON 原始字节；读写均限制 2 MiB。旧格式不允许携带非默认人像数据。
- `editor.rs`、`export_job.rs`、`batch.rs`：预览/单张/批量共用配方。公共批量模式只同步全局参数和白平衡，保留各目标自己的面部绑定，避免把第一张脸的位置套给其他原片。
- `native/crates/desktop/{src/main.rs,src/qa.rs,ui/main.slint}`：选择可选组件、本机后台检测、面部切换、柔化、显示框、清除、撤销和恢复。检测结果与源文件、选片、编辑版本校验；切图/改参数/取消/退出不接受旧结果。面部框与五点使用照片实际适配/放大区域。另修复缩略图使用原生尺寸溢出的问题，并复看窗口。
- `native/crates/vision/src/detector.rs`：复用核心几何类型，显式关闭 ORT 环境遥测；模型输入和定位算法保持阶段 5A 契约。
- `tools/prepare_native_vision.py`、`native_build.ps1`、`package_native.py`：显式可选组件安装、固定七文件/模型/DLL/许可/普通及延迟依赖审计；基础打包器原有的延迟导入拒绝规则保持。新增 `-VisionRuntime`，包内明确声明 VC++ x64 外部依赖。Rust ORT 包装层的 MIT 许可随包保存。

柔化在未量化 sRGB 中只修正亮度中等尺度起伏；滑动盒均值为 O(ROI 像素数)，采用 f64 累加、边界羽化、眼口保护、局部边缘抑制和增益上限。RGB 共同增益保留通道比例，避免独立通道剪切。区域来自框与五点几何，不能宣称分辨了皮肤、头发或眼镜；默认检测后的强度为零，由用户决定是否应用。一次只处理一张选中面部。

## 验证

提交前 Windows GNU 工作区 Rust 66 项通过、2 项外部 fixture 默认 ignored；关闭遥测后再次复跑，并显式通过公开 12/14 位 RAW 全尺寸/半尺寸与固定 CPU 人脸各一项 fixture。新增回归覆盖不同路径但同大小/时间戳、旧草稿保护、四分之一/半/全尺寸遮罩几何、眼口/区域外不变、通道比例、细纹对比度至少保留 90%、独立均值参考、撤销/AI 保留、逐张批量绑定，以及实际预览与 TIFF16 量化一致。

`tools/smoke_native_portrait.py` 在隔离中文目录内，通过实际 Slint 回调运行 18 项：v2 原字节备份迁移、检测零强度、真实像素变化、撤销/重做、全局编辑保留、逐张批量、TIFF16、正常流程原片不变、重启恢复、导出逐字节一致、源变化拒绝、清除恢复、检测中切图与退出。为验证拒绝旧位置，脚本只会刻意修改自己的测试副本，并在报告明确标注；外部公开原图保持不变。Debug 和两次 Release 全部通过，最终随包测试以本机检查点为准。

旧 Python 完整 suite 175 项（173 通过、2 跳过），Node 31 通过。既有 RAW/批量/编辑窗口 14/14/26 项通过，模拟 CLI 61 项和本机 HTTP 45 项通过，无真实云端请求。实际窗口使用 Computer Use 点击检测/柔化到 70.16，检查面部框/五点与留边照片对齐；缩略图修复后重启复看正确。组件目录对话框、复杂多脸、高 DPI 和用户 Z30 人像未做实机验收。

公开 Z30 12/14 位 RAW 在关闭人像修饰时，两份完整 TIFF16 与阶段 4C 的文件 SHA-256 完全相同。一次窗口观测中，批量耗时 4.306→4.326 秒，峰值工作集 551.363→551.391 MiB；重复单张导出 .989→.993 秒。不是受控多轮性能结论。512 像素公开人像 Release 流程峰值约 77 MiB、检测中退出约 .18 秒；不代表全尺寸 Z30 人像或所有退出情形。

数据见 `native-stage5b-portrait.json`。这些是提交前明确标记为 dirty 的验收构建；最终干净提交、打包哈希、解压复测和对应 CI 状态另记本机 `.development/checkpoint.json`，不能用旧构建的成功替代最终包复测。

## 分发与剩余风险

可选组件包含固定 YuNet 模型和 ONNX Runtime CPU。基础程序启动和已保存的几何柔化不需要加载推理 DLL；新检测仍需本机 Microsoft VC++ x64 系统运行库，组件未提供该系统依赖，也没有通过干净 Windows 验收。普通 `-RawRuntime` 构建保持不含模型；追加 `-VisionRuntime` 才把已校验的组件复制到 `vision/`，没有自动下载或系统安装。

公开 astronaut 不是用户实拍或专业画质样本。真实肤质/暗光/强侧脸/眼镜/多肤色/婚礼多人、Z30 人像细节、跨预览分辨率滤波观感仍需用户样片验证；几何回归不等于完整视觉质量验收。原有 CLI 登录、可选后端和原片只读原则保持。阶段 5C 后续先补更可靠的皮肤区域，再实现其他精修能力。
