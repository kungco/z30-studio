# 阶段 2C 性能补充：保留浮点精度的离散 ICC 缓存

2026-10-25。此报告接续 native-stage2c.md，保留其优化前耗时，不改写历史数据。

## 实际修改

colour.rs 增加 to_linear_raster，显式要求 8/16 位离散采样值；普通 float 数据仍走原 to_linear。纯 RGB 矩阵/TRC 配置到线性目标是可分离变换：通过完整 LittleCMS 在每个实际源码值上计算三条 RGB 响应轴，再叠加并扣除重复黑点。不猜 gamma/白点、不做 3D 近似插值；16 位输入使用每通道 65536 个采样，不退回 8 位。小图直接使用 CMS，避免表构建成本。

含 AToB/DToB LUT 的 RGB 配置明确排除；异常大响应也回退通用 CMS。灰度按全部实际灰阶建立一维浮点输出表。raster.rs 三处 ICC/gAMA/Adobe 转换实际接入新接口，保留非法输入、范围/有限值检查和源文件只读策略。

## 质量验证

- Rust 25 项通过，1 个真实 RAW fixture 常规明确 ignored；52 个文件回归和 5 个独立浮点缩放参考仍通过。
- 新测试覆盖全部 8/16 位码值，并混合 RGB 通道，对 sRGB、宽色域及非零黑点曲线逐点比较缓存路径与未缓存的通用浮点 CMS，最大误差要求保持 2e-6。灰度相同对照逐位一致。
- 构造同时具有矩阵/TRC 标签及非线性 AToB 覆盖的内存测试配置，验证不会误走可分离路径；不把此合成测试称为真实打印 LUT 配置验收。
- 四组全尺寸合成输入/原片 SHA、外部探针及原有质量阈值全部保持；报告 native-raster-icc-optimized.json。两组无 ICC JPEG 与固定旧 Python 逐位一致；带 ICC JPEG 最大差异 4.18e-6，RGB8 回编码一致；RGB16 PNG 对解析梯度最大 2.69e-7。未放宽阈值。

## 测量与限制

同机单次 5568×3712 sRGB ICC JPEG，优化前约 11.799 秒/302 MiB，优化后 .506 秒/302 MiB；旧 Python 约 1.1 秒/1357 MiB。无 ICC JPEG 约 .31 秒，RGB16 PNG 约 .62 秒。均为实际 worker 的 Windows 峰值工作集，不统计 Python venv 重定向进程；只有单次结果，负载/频率差异存在，不宣称普遍加速倍数。

复杂 RGB LUT 输入仍可使用通用 CMS，速度未优化；CMYK/YCCK、cICP/HDR、动画 PNG 仍拒绝。尚未做显示器 ICC、用户实机/校准显示器/肤色灰卡/打印验收。编辑/导出 GUI、真实全尺寸 NEF 最终文件导出和阶段 3–6 继续等待验收，不能以本次优化宣称整款软件完成。
