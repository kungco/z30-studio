# 局部蒙版与修复

范围蒙版在“局部调整”中添加：亮度范围基于显影前场景亮度，颜色范围使用感知颜色距离；拖动范围/过渡/容差，点击显示覆盖检查。支持反向、羽化、颜色与曝光控制。最多 32 个蒙版、总计 8192 个画笔点。语义位图最长 256 像素边的本地模型结果会按最终构图映射至输出；重新裁剪、拉直、旋转后需要检查。

“本地 AI 蒙版”只在本机 CPU 推理。首次点击下载会从固定 Hugging Face 地址获取约 15 MB ONNX 权重，以固定 SHA256 验证并原子安装；不会上传照片，不需要云端 API Key，也不使用 Codex 额度。没有安装模型不影响手动调色、范围蒙版和修复。主体选择为排除场景背景/大平面后的最大对象连通区域；天空与人物是 ADE20K 语义类别。生成后默认不改变曝光，可显示覆盖、反向和调整强度。

模型是 [Xenova 的 ONNX 转换](https://huggingface.co/Xenova/segformer-b0-finetuned-ade-512-512)，对应 [NVIDIA SegFormer B0](https://huggingface.co/nvidia/segformer-b0-finetuned-ade-512-512)。权重不随源码或 Windows 包再分发，使用需遵守 [原模型许可](https://github.com/NVlabs/SegFormer/blob/master/LICENSE)。本地使用 [ONNX Runtime CPU](https://onnxruntime.ai/docs/get-started/with-python.html)。默认路径为用户数据目录 models/；可显式设置 Z30_LOCAL_MODEL_DIR 以使用同一校验权重的已有目录，不接受网页任意文件路径或远程模型代码。

污点修复使用附近自动取样与均值匹配的浮点修复，克隆先点取样再点目标。每个点记录明确的取样坐标、半径、强度与羽化；预览与导出使用同一个取样位置。最多 256 点，随历史/草稿/项目保存，取样基于修复前画面。它们不是生成式填充，不承诺修复大范围遮挡、失焦或缺失内容。

肤色柔化先生成本地人物区域，再结合宽泛暖色选择和传统边缘保留降噪。它不是面部关键点/精细皮肤分割，可能影响暖色衣物；低强度使用并检查纹理。没有人物区域时不能开启，失败不使用虚构蒙版替代。删除/撤销只修改参数，不修改 NEF/JPEG。

发送给 Codex/兼容服务的提示仅包含受限调色与构图数值；不会把语义位图、修复数据、灰卡名称、镜头自定义名称或选片元数据塞进文字提示。仍只有两张去 EXIF/GPS 的缩小 JPEG 作为视觉输入。
